# 项目结构说明

整理日期：2026-11-20。目录按“代码 / 资源 / 数据 / 文档 / 构建”分层，代码模块仍全部留在根目录，import 与打包入口不变。

## 根目录（代码与入口）

| 文件 | 作用 |
| :--- | :--- |
| `main.py` | 程序入口，首页、菜单、设置页、状态机与 3D 子进程调度 |
| `config.py` | 常量与配置；同时定义 `BASE_DIR` / `DATA_DIR`（存档统一落 `data/`） |
| `utils.py` | 资源路径 `resource_path()`、字体、设置与存档读写、画面缩放换算 |
| `game.py` | 经典单人模式 |
| `ai_mode.py` | AI 自动演示模式 |
| `versus_mode.py` | 人机对战（2D） |
| `netbattle_mode.py` | 双人联机对战（2D） |
| `network.py` | 联机协议与报文封装 |
| `sky3d_mode.py` | 3D 天空贪吃蛇主模块（世界生成、相机、转向、安全区） |
| `sky3d_ai_mode.py` | 3D 天空人机对战 |
| `sky3d_net_mode.py` | 3D 天空联机 |
| `home_bg.py` `home_scene.py` | 首页动态背景与帧序列播放 |
| `menu_art.py` | 二级菜单设计稿底图与按钮热区换算 |
| `ui.py` | 通用 UI 组件（按钮、弹层、图表等） |
| `像素贪吃蛇.spec` | 当前唯一的打包配置（PyInstaller） |

## 子目录

| 目录 | 内容 |
| :--- | :--- |
| `assets/` | 图片、全景、首页帧序列 `*.bin`、图标 `icons/` |
| `assets/audio/` | 音效：`eat.wav` `death.wav` `game.wav` `menu.wav` |
| `assets/fonts/` | 中文字体：`msyh.ttc` `msyhbd.ttc` `msyhl.ttc` |
| `assets/_archive/` | 未参与打包的中间素材（如 `home_bg_wide_1/2.jpg`） |
| `data/` | 运行时数据：`settings.json` 及各模式最高分、联机战绩 |
| `docs/` | 文档（README、AI 使用声明、本说明）与 `screenshots/` 验证截图 |
| `logs/` | 历史运行日志 `run_out.log` `run_err.log` |
| `build_old/` | 旧打包配置（`main.spec` `SnakeGame.spec`）、上次 PyInstaller 中间产物、旧 `__pycache__` |
| `tools/` | 一次性脚本（如生成《AI 使用声明》的 `_make_ai_decl.py`） |
| `tests/` | 单元测试（`test_steer.py` 转向方向与死区） |
| `dist/` | 打包成品 `像素贪吃蛇.exe` |
| `venv/` | 本地虚拟环境（不参与分发） |

## 路径规则（整理时同步修改）

- 读资源：一律走 `utils.resource_path()`，基准是脚本所在目录；打包后自动切到 `_MEIPASS`。
- 读写存档：走 `config.DATA_DIR`，源码运行为脚本旁 `data/`，打包后为 exe 旁 `data/`。
- 3D 模块：`application.asset_folder` 在源码运行下显式指向脚本目录，不再依赖启动时的当前工作目录。
- 因此从任意目录启动（`python D:\...\main.py`、双击 exe、快捷方式改了起始位置）都能正确找到资源与存档。
