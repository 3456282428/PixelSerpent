## 一、项目概览

同一个人项目里跑着两套渲染引擎、五种玩法，共用一份设置、一套存档和同一套画布——菜单 1920×1080，游戏内 960×540 上采样。



| 玩法          | 引擎               | 入口                | 简介                           |
| ----------- | ---------------- | ----------------- | ---------------------------- |
| 经典单人        | pygame 2D        | 首页 › 经典贪吃蛇 › 选择难度 | 网格移动、吃食加分、金色食物、最高分与最近 10 局记录 |
| AI 演示       | pygame 2D        | 同上（AI 自动模式）       | BFS 寻路自动游玩，可观察 AI 行为         |
| 人机对战        | pygame 2D        | 首页 › 经典 › 人机对战    | 与 AI 同场竞技，限时 / 不限时，障碍与道具     |
| 双人联机（2D）    | pygame 2D + TCP  | 首页 › 经典 › 联机对战    | 主机权威，房间码或 IP 加入              |
| 天空贪吃蛇（3D）   | Ursina + Panda3D | 首页 › 天空贪吃蛇        | 空中飞行、俯冲爬升、安全区缩圈、光环与道具        |
| 天空人机 / 天空联机 | 同上（exe 内同进程桥接）   | 天空 › 人机对战 / 联机对战  | HP 制对战、近程爪子与远程弓箭             |

技术栈：Python 3.13.9（conda 自由线程）、pygame 2.6.1、ursina 8.3.0、Panda3D 1.10.16、Pillow、numpy。

## 三、模块职责

### 3.1 入口与基础设施



| 模块          | 职责                                          | 关键实现                                                               |
| ----------- | ------------------------------------------- | ------------------------------------------------------------------ |
| `app_shell.py` | exe 入口与窗口壳：2D 离屏渲染成纹理、3D 同进程构建、窗口居中与缩放、F11 全屏、鼠标坐标换算 | `SDL_VIDEODRIVER=dummy` 跑 `main.main()`；`pygame.display.flip` 被替换为上传纹理；启动补 `WS_THICKFRAME` 让窗口可缩放；每帧不超过 90 帧时按实测尺寸居中一次 |
| `main.py`   | 主循环、页面状态机、键鼠事件分发、独立运行时的 3D 子进程拉起与回收、菜单音乐 | `START_STATE` 环境变量可指定启动页便于截图自查；`python main.py` 下用 `sys.executable` 起 `--sky3d` 子进程，exe 内改由 `app_shell` 同进程构建 |
| `config.py` | 所有可调参数、颜色、皮肤、按键默认值、房间与 3D 参数                | `BASE_DIR` 源码取脚本目录、打包取 exe 目录；`DATA_DIR = BASE_DIR/data` 并在导入时创建   |
| `utils.py`  | `resource_path()`、中文字体池、设置与三类存档读写、坐标换算、图形工具 | 字体按字号缓存；资源缺失时逐级回退到系统字体                                             |
| `ui.py`     | 按钮（悬停缩放）、暂停 / 退出 / 结束弹层、历史成绩折线图、渐变背景        | 折线图在窗口内直接绘制，不阻塞主循环                                                 |

### 3.2 2D 玩法



| 模块                  | 说明                                                   |
| ------------------- | ---------------------------------------------------- |
| `game.py`           | 网格 48×27（格子 40px）、线性插值移动、金食物、皮肤渐变、暂停与结算              |
| `ai_mode.py`        | 与 `game.py` 同一套玩法，控制权交给 BFS AI                       |
| `versus_mode.py`    | 玩家 vs AI：障碍数量按难度 8/14/20，出生安全半径 4，限时模式可选             |
| `netbattle_mode.py` | 双人联机：主机跑完整模拟，客户端发输入、收快照；房间参数（速度 / 障碍 / 食物 / 时长）由房主下发 |
| `network.py`        | 每条消息一行 JSON；房间码把 IPv4 编成 7 位 36 进制，端口固定 50007        |

### 3.3 3D 玩法



| 模块                             | 说明                                                                      |
| ------------------------------ | ----------------------------------------------------------------------- |
| `sky3d_mode.py`                | 世界 6400×6400（`SKY_WORLD_SIZE×2`）、渲染缩放 `SC=0.1`、自动前进 230/s、最大转向 14 rad/s |
| `sky3d_ai_mode.py`             | 复用主模块世界与相机，对手换成 AI                                                      |
| `sky3d_net_mode.py`            | HP 制对战：初始 100 血、180 秒、主机 20Hz 快照、客户端 60ms 上报输入                          |
| `home_bg.py` / `home_scene.py` | 首页两套背景：静态高清底图与 243 帧循环帧序列（`assets/home_loop_hd.bin`，42.2MB）             |

3D 模块内部要点：



* **转向**：`_RawMouse` 用 Win32 `GetCursorPos` 取位移、读完立即 `SetCursorPos` 钉回客户区中心，配合 `ShowCursor(FALSE)` 隐藏光标；`SPI_SETMOUSE` 关闭指针加速（仅会话内生效、退出还原）；`GetForegroundWindow` 判定保证 Alt+Tab 后不产生误转向。

* **相机**：第三人称追尾 `CAM_DIST=16`，俯仰 `PITCH_LIMIT=1.05`（60°）避开 `look_at` 上方向退化，垂直方向非对称平滑（抬升 7、下落 16），水平位置刚性跟随。

* **安全区**：开局 20 秒后开始，警告 10 秒、收缩 30 秒、稳定 30 秒；半径 6 档 0.50→0.14，圈外伤害 3→12 DPS，固定种子 20261118 保证联机双方圈位一致。

* **软墙**：内缩 60、缓冲 190、外推 200/s（低于前进速度），墙高 46 拆成 10 层透明度渐变。

* **空中内容**：16 个光环（穿越 +5 经验并补能量）、5 种强化道具（护盾 / 磁铁 / 双倍 / 加速 / 幸运）。

### 3.5 窗口与呈现

exe 的窗口完全由 `app_shell.py` 接管，四条行为都在这里：



* **启动居中**：建窗后取 `GetWindowRect` 实测尺寸，按 `(屏宽-窗宽)/2`、`(屏高-窗高)/2` 摆位，用 `SetWindowPos` 并带 `SWP_NOSIZE|SWP_NOZORDER|SWP_NOACTIVATE`，不改 Z 序、不抢焦点，同时把 Ursina 的 `win.set_origin` 同步过去。
* **可拖动**：不再定时把窗口拉回固定位置，也不置顶，拖动标题栏后位置保持不变。
* **可缩放**：启动时给窗口补 `WS_THICKFRAME|WS_MAXIMIZEBOX|WS_MINIMIZEBOX`（glfw 建窗默认缺这三项，拖不动边角），缩放后画面等比 letterbox 居中留黑，鼠标坐标经 `_region` 从客户区换算回设计坐标，按钮命中不受影响。
* **F11 全屏**：记录进入前的 rect，退出全屏按原尺寸原位置还原；全屏与缩放互不干扰。

呈现侧的逐帧校正：主循环开头以 `pygame.display.get_surface()` 作为真实画布，再按当前状态决定是否换用 960 离屏层。早期版本直接沿用上一帧的 `game.screen`，从联机页（低清层）返回二级菜单（高清层）时会停留在旧尺寸，画面画在 960 上、`flip()` 翻的却是没更新的 1920 表面，窗口就此卡死；改为每帧校正后，天空与经典两条联机返回路径均正常。

## 八、路径规则（整理时的核心改动）

原先资源以 “当前工作目录” 为基准，从别的目录启动会整片丢资源；存档也写到启动目录，容易出现两套存档。现在统一为：



```
# utils.py
_BASE_DIR = os.path.dirname(os.path.abspath(__file__))

def resource_path(relative_path):
    if hasattr(sys, '_MEIPASS'):          # 打包后：解压目录
        return os.path.join(sys._MEIPASS, relative_path)
    return os.path.join(_BASE_DIR, relative_path)   # 源码：脚本目录
```



```
# config.py
if getattr(sys, "frozen", False):
    BASE_DIR = os.path.dirname(os.path.abspath(sys.executable))  # exe 旁边
else:
    BASE_DIR = os.path.dirname(os.path.abspath(__file__))
DATA_DIR = os.path.join(BASE_DIR, "data")
```

3D 侧把 ursina 的 `asset_folder` 也固定在脚本目录（打包后仍取 `_MEIPASS`），避免依赖 cwd。

结果：源码从任意目录启动、双击 exe、快捷方式改了起始位置，三者都能正确找到资源与存档。

## 九、运行与打包

### 源码运行



```
cd D:\python\src\pythonhomework
.\venv\Scripts\python.exe main.py            # 2D 主程序
.\venv\Scripts\python.exe sky3d_mode.py      # 单独调试 3D
$env:SKY3D_TEST='1'; .\venv\Scripts\python.exe sky3d_mode.py   # 3D 离屏自检
$env:START_STATE='settings'; .\venv\Scripts\python.exe main.py # 直接进设置页
```

3D 场景有两条启动路径：`python main.py` 用 `sys.executable` 起子进程，源码模式传脚本绝对路径，打包后传 `--sky3d` / `--sky3d-ai` 参数自调用；打包 exe 走 `app_shell.py`，在同一个 Ursina 窗口里直接构建 3D 场景，不再起子进程，因此没有起窗空档与画面闪断。

### 打包



```
.\venv\Scripts\pyinstaller.exe --noconfirm --clean '像素贪吃蛇.spec'
```

配置要点：



* `datas` 覆盖全部运行期资源（音频、字体、菜单底图、全景、光环、图标、首页帧序列）。

* `_extra_dlls` 手工收集 conda 运行时库（`ffi.dll`、`ffi-7/8.dll`、`libcrypto-3-x64.dll`、`libssl-3-x64.dll`、`sqlite3.dll`、`zlib.dll`），否则 frozen 下 `_ctypes` 导入失败。

* `collect_all` 打包 ursina、panda3d、pandac；`hiddenimports` 显式声明三个 3D 模式模块。

* 产物为单文件 `dist/像素贪吃蛇.exe`（约 157MB），`console=False`。

## 十一、跨机部署注意



1. **免安装**：单文件 exe 已内置 `python313.dll`、`VCRUNTIME140.dll`、`VCRUNTIME140_1.dll`、`panda3d\MSVCP140.dll`、`ffi/ssl/crypto/sqlite3`，目标机无需装 Python 或 VC++ 运行库。

2. **3D 依赖 OpenGL**：远程桌面、虚拟机、老旧核显可能起不了 3D 窗口；2D 有 SDL 软渲染兜底。崩溃日志在 `%TEMP%\sky3d_crash.log`。

3. **存档位置**：`data/` 生成在 exe 同目录。放桌面会多出一个 `data` 文件夹；放只读目录（如 `Program Files`）保存会静默失败。

4. **首次启动慢**：onefile 每次解压 157MB 到 `%TEMP%\_MEIxxxx`，冷启动十秒级；无签名，SmartScreen 可能提示。

5. **联机**：需放行 50007 端口，双方同一网段；房间码只在局域网内有意义。

## 十二、已知限制与后续可做



* 联机未做断线重连与 NAT 穿透，跨公网需自行搭端口映射。

* 首页高清帧序列 42.2MB，占 exe 体积约四分之一；如需瘦身可降到 960×540 或改硬件视频解码。

* `docs/screenshots/shots_hd` 为 26 张高清验证截图（37.9MB），属过程材料，可另行归档。

* `build_old/` 内两份 PyInstaller 中间产物共约 330MB，确认不再回溯旧构建后可整体删除。

* 3D 全屏下 `SetCursorPos` 在个别驱动的独占全屏模式可能被忽略，已按 “回中失败则降级为摇杆式相对控制” 预留判断。

* 高清菜单页每帧要把整张 1920×1080 表面上传成纹理，`SHELL_PERF=1` 实测 60–91 ms/帧（菜单页约 11–16 fps）；游戏内走 960 路径不受影响，如需提速可改成只上传脏矩形或直接双缓冲绘制。

* 窗口缩放是等比 letterbox，画面固定 16:9，超宽或超高的窗口只会多留黑边，不会重排 UI。
