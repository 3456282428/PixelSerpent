# 🐍 像素贪吃蛇

一个功能丰富的贪吃蛇游戏，包含**单人模式**、**AI 自动模式**和**人机对战模式**，支持难度选择、内置历史成绩图表、动态特效、鼠标/键盘双控制及可滚动操作说明。

---

## 📋 功能特性

- **三种游戏模式**
  - **单人模式**：玩家使用方向键/WASD 控制蛇，吃到食物得分，撞墙或撞自身结束。
  - **AI 自动模式**：基于 BFS 寻路算法，AI 蛇自主寻找食物并避开障碍，玩家可观察 AI 行为。
  - **人机对战模式**：玩家与 AI 同场竞技，看谁吃到的食物更多，AI 难度可选（简单/普通/困难）。

- **难度选择**（单人/AI/对战均支持）
  - 简单（慢速）、普通（中速）、困难（快速）。

- **特殊食物系统**
  - 每吃 5 个普通红色食物，会生成一个金色特殊食物，食用后 +5 分，限时出现。

- **历史成绩**
  - 记录最高分和最近 10 次得分。
  - **无需额外依赖**：直接在游戏窗口内绘制折线图，点击即可查看，不阻塞主循环。

- **操作便捷**
  - 键盘控制：方向键 / WASD 移动，P 键暂停/恢复，ESC 打开暂停菜单。
  - 鼠标控制：游戏进行中点击屏幕任意位置可暂停/恢复。
  - 帮助窗口内支持鼠标滚轮滚动查看全部说明。

- **暂停菜单**
  - 按 ESC 弹出，提供“继续游戏”和“返回菜单”两个按钮，简洁直观。

- **视觉特效**
  - 星空动态背景、食物脉动、蛇身渐变色、按钮悬停缩放动画，游戏体验流畅。

- **平滑移动**
  - 蛇身采用线性插值动画，移动更顺滑。
